What it checks

Every token in the design system

It reads every nested layer in your selection (frames inside frames, text inside components) and compares it with gra.UI.ty.

Color

Fills, strokes and text colours, matched to bg, text and border tokens.

Text

Text styles. Line height can be up to 4px off; everything else must match.

Radius

Each corner, matched to the corner-radius tokens.

Spacing

Auto-layout gap and row gap, matched to the spacing tokens.

Padding

Every side of auto-layout padding, matched to the spacing tokens.

Install · once, about 2 minutes

Get it into Figma

Token Swapper runs as a development plugin, so it lives in a folder on your computer.

Download and unzip it somewhere permanent

Download the zip and move the Token Swapper folder somewhere you won't delete, like Documents/Figma plugins. Figma runs the plugin from this folder.

Open the Figma desktop app

Development plugins only run in the desktop app, not in the browser.

Import the plugin

Open any design file, then go to Menu › Plugins › Development › Import plugin from manifest… and pick manifest.json inside the folder.

Enable the gra.UI.ty library in your file

Fixes link to the published library, so each file needs it on: Assets panel › Libraries › gra.UI.ty Design System › Enable.

Run it

Plugins › Development › Design Token Swapper (gra.UI.ty). Tip: right-click the canvas and use Run last plugin next time.

Updating: download the new zip and replace the three files in the same folder. Figma picks up the new version the next time you run it, so you don't need to import it again.
First run

Set it up once

Settings open by themselves on the first run and are remembered after that. Change them any time with the gear.

Invert mode

Turn it on for dark screens. A screen only ever gets one family: default or invert tokens, never both.

Fix legacy bindings

Also move layers that are on old tokens or styles (anything not gra.UI.ty) over to the new tokens.

What to check

Switch text styles, spacing and padding, or corner radius on or off. Colours are always checked.

How to use it

Select. Scan. Apply.

1 · Select a frame

A screen or the whole flow. It scans as soon as you select, and shows progress with a time estimate.

2 · Read the overview

Tiles count what was found per type. Click a tile to see just that type.

3 · Review the rows

Each row reads old → new. Tick the ones you want, and pick another token if the suggestion isn't right.

4 · Apply

Links every ticked row to the library. When nothing's left, you get Good to go, ready to send to dev.

The sections

Ready to apply

An exact match. Ticked by default.

Resolved via context

Several tokens fit, so it picked one using a clue: theme-aware over static, the component's name, other copies, closest line height, or a difference too small to see. Hover ⓘ to see which.

Needs your pick

Several tokens fit and nothing decides it. Choose one.

Check before replacing

The nearest token looks visibly different (ΔE over 5). Most severe first; hover ⚠ to see how likely it is to stand out.

15% · low50% · medium95% · high

No matching token

No exact token, but a close one is suggested. This includes off-scale spacing and radius, and text styles that don't match.

Inside components

Found inside component instances, many from legacy libraries. Fixes here become overrides on that copy.

Left alone

Plain hex colours in illustrations and logos, colours with opacity, negative spacing, and anything you ignored. Old tokens still get flagged, even inside artwork.

Tips

Work faster

Fix repeats once

Table cells, list rows and cards with the same problem become one ×12 similar row. Fix it once and all twelve are done. Click the badge to split them out.

Right-click to ignore

Ignore this layer, or everything in its group, like an illustration whose colours are on purpose. Or Check this anyway on something left alone. Saved in the file for the whole team.

Apply or Replace

Tick several and hit Apply, or use the swap icon on one row. Your other ticks and picks stay put.

Light or dark

For dark screens, turn on Invert mode in settings. A flow with both needs two runs, one per mode.

Case matters

All-caps text is only matched to uppercase styles, like the overlines.

Hover for details

The row shows names; the ⓘ shows exact values: hex, ΔE, font, size, line height and letter spacing.

Help

Troubleshooting

“Couldn't load … from the library”

The gra.UI.ty library isn't enabled in this file. Go to Assets panel › Libraries › gra.UI.ty Design System › Enable, then apply again.

I can't find the plugin under Plugins › Development

Use the Figma desktop app, not the browser. If you moved or deleted the folder, import manifest.json again from its new location.

A spacing fix inside a component failed

Figma doesn't let you change some layout settings, like padding and gap, on layers inside a component copy. Fix it in the main component instead. Colours and text styles inside components work fine.

The colour I expected isn't suggested

gra.UI.ty may not have that token. For example, there's no mid-grey bg token for grey icons. If the colour is intentional, right-click the row and choose Ignore. If it's a gap in the system, raise it with the DS owners.

It's stuck on “Applying…”

After 30 seconds without a response it tells you so. Open Plugins › Development › Show/Hide console, copy the error, and send it over.

The layer I clicked is behind the plugin window

The plugin frames layers to the left of its window, which is where Figma opens it. If you dragged the window to the left side, move it back to the right.
